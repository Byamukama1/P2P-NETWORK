⚠️ Important Security Guide

1. Open Binance or your wallet app.

2. Select USDT → Receive/Deposit.

3. Copy your wallet address.

4. Paste it here. Do not type manually.

5. Select the same network.

TRC20 address must use TRC20.
BEP20 address must use BNB Smart Chain.

Wrong network selection can permanently lose USDT.
